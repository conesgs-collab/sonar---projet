# SONAR-SE — base de regles du diagnostic intelligent (deterministe, hors-ligne).
#
# Format : un enregistrement par ligne, champs separes par " :: " (espace,
# deux-points, deux-points, espace). Lignes commencant par # ignorees.
#
#   ID :: GRAVITE :: SYMPTOMES :: QUAND :: RENFORTS :: BASE :: TITRE :: CAUSE :: ACTION :: PROFIL :: A_EVITER
#
# GRAVITE   CRITICAL | HIGH | MEDIUM | INFO
# SYMPTOMES liste separee par des virgules parmi boot,bsod,slow,data,password,
#           virus,other — ou * (toujours pertinent). Un symptome signale par le
#           technicien qui figure dans la liste ajoute +10 de confiance.
# QUAND     conditions reliees par " && ". Chaque condition : CLE OP VALEUR
#           OP : ==  !=  >  >=  <  <=  ~ (regex)  !~   ou  "CLE exists" /
#           "CLE missing". Une CLE contenant * s'evalue une fois par instance
#           (ex. disk.*.smart_overall : un constat par disque) ; tous les *
#           d'une regle designent la meme instance.
# RENFORTS  "CONDITION=>+N" separes par " ;; " : si la condition est vraie, la
#           confiance augmente de N (indices concordants). "-" si aucun.
# BASE      confiance de depart, en % (1-99).
# Dans TITRE/CAUSE/ACTION/A_EVITER : {@} = nom de l'instance, {cle} = valeur
#           d'un fait ({*} dans la cle designe l'instance).
# PROFIL    profil SONAR-SE associe (boot-repair, data-recovery, malware,
#           disk-clone, password-reset, hardware-diagnostic, general-os) ou -
#
# Principe : une regle ne conclut jamais plus que ses preuves. Le moteur
# affiche toujours les faits qui l'ont declenchee.
